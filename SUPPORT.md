# Support

These are small open-source projects, and support is best effort. No response time is promised.

- **A question:** use [Discussions](https://github.com/orgs/gramatr/discussions). It is the right place for how a guard behaves, what it does and does not catch, and how to configure it.
- **A bug:** open an issue with the bug report form. Give the version and describe the shape of the input; never paste a real credential or personal data.
- **A change you would like:** open an issue with the proposal form first. See [CONTRIBUTING.md](CONTRIBUTING.md).
- **A security problem:** report it privately, never in public. See [SECURITY.md](SECURITY.md).
- **You cannot use GitHub:** write to support@gramatr.com. Replies are best effort.
- **Before you ask:** each project has a `docs/` folder with the limits, the trade-offs and the configuration, written to be read before you rely on the guards.

We do not offer support for the grāmatr platform here. For that, see [gramatr.com](https://gramatr.com).
