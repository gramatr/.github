# Security policy

This is the default security policy for grāmatr's public repositories. A repository with its own `SECURITY.md` follows that one instead; the guards repositories do.

## Reporting a vulnerability

Please report security problems privately, through GitHub's private vulnerability reporting: open the **Security** tab of the repository concerned and choose **Report a vulnerability**. Please do not describe a vulnerability in any public place (an issue, a pull request, a discussion, a social post): a public report discloses it to everyone at once.

If you cannot use GitHub, write to security@gramatr.com instead. Please do not put the details of a vulnerability in a public place, and never include a real credential.

These are small open-source projects. Replies are best effort and no response time is promised. A report that is clear, reproducible and about something in scope is the most likely to be acted on quickly.

## What to send

Describe the shape of the finding and the steps to reproduce it. Never include a real credential, token, key or personal data, not even a rotated or expired one. Use a fabricated value with the same shape, and say which behaviour it exercises.

## Supported versions

Only the latest release of a project is supported. Fixes are made on the main branch and shipped in a new release.
